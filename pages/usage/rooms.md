# 一起看房间

## 创建房间

拥有创建权限的用户（`root` / `admin`，或管理员开启了「所有用户可创建房间」时）在首页进入「开始共享」即可创建房间：

- 房主拥有播放控制权：**播放、暂停、跳转、倍速**。
- 可配置房间名称、房间模式与各项设置（弹幕、语音等）。

## 加入房间

- 通过房间号 / 分享链接加入。
- 加入后观众实时跟随房主的播放进度。
- 观众可**申请控制**（如申请跳转进度或暂停），房主在播放器左上角查看通知并确认后执行。

## 播放控制与同步

- 房主操作（播放/暂停/跳转/倍速/换片）通过 Socket.IO 实时同步给所有观众。
- 支持 `track-change`（切换音轨）等细粒度同步。

## 播放记忆与断线接管

系统在服务端持久化房主的播放状态（当前影片、播放位置、速率）：

- **房主短暂断线后**，由服务器继续广播当前状态（按 `当前时间 + 已播放时长 × 速率` 推算），观众无需中断观看。
- **房主离线超过 10 分钟**自动关房，期间观众可自由控制。

## 房间管理操作

| 操作 | 说明 |
| --- | --- |
| 修改房间名 | 房主可随时更新房间名称 |
| 更新房间设置 | 弹幕开关、语音比特率、共享方式等 |
| 踢出观众 / 静音 | 房主可踢出或临时静音某位观众 |
| 移交房主 | 房主可将控制权移交给房间内其他用户 |
| 关闭房间 | 房主主动关闭；离线超时自动关闭 |

## 权限边界

- 房间控制权属于 `root` 或房主本人（`canControlRoom` 校验）。
- `admin` 可完全控制**自己创建**的房间，但不能删除他人的房间。
- `root` 可创建/控制/删除任意房间。

## 相关接口

- 房间 REST API：`/api/rooms`（详见 [API 参考](/development/api)）
- 实时事件：`create-room`、`register-host`、`request-join`、`approve-join`、`watch-together-state` 等（详见 [后端文档](/development/backend)）
