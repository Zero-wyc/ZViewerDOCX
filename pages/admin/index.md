# 管理员指南

本章面向 `root` / `admin` 角色，介绍管理后台（`/admin` 页面）与相关配置。

| 章节 | 内容 |
| --- | --- |
| [用户与权限](/admin/users) | 四层权限模型、注册审核、角色管理 |
| [系统设置](/admin/settings) | 注册模式、房间创建模式、番剧源、Beta 开关 |
| [挂载点管理](/admin/mounts) | WebDAV / FTP / OpenList 连接配置 |
| [服务器文件与下载](/admin/server-files) | 本机目录浏览、上传、Bilibili 视频下载 |
| [更新管理](/admin/updates) | 自动更新、预发布控制、手动上传 |

## 权限速览

| 角色 | 说明 |
| --- | --- |
| `root` | 超级管理员：全部管理能力，可审核用户、修改角色、删除任意房间 |
| `admin` | 管理员：可管理自己的房间与部分后台功能，不能删除他人房间 |

> 管理后台页面（`/admin`）仅 `admin` 及以上可访问；部分敏感接口（用户审核、系统设置、更新、服务器文件）仅 `root` 可访问。
