# 功能说明

## 一起看房间

- 首页「开始共享」创建房间（一起看 / 投屏两种模式），或「加入房间」输房间号 / 房间列表 / 分享链接加入。
- 房主控制播放、暂停、跳转、倍速、切换影片，进度实时同步给观众。
- 观众可申请控制（暂停 / 跳转等），房主在播放器左上角收到通知后决定是否通过。
- 房主离线时观众自动进入自主控制模式；房主主动离开后房间进入宽限期，右上角可一键回到房间；离线超时 10 分钟自动关房。
- 房间支持密码、加入审批、观众权限设置。
- 房主可任命房管：协助管理影片、禁言 / 踢出观众、语音禁言与移出。
- 房间页左下角实时显示当前房间上下行流量。

## 一起听音乐

- 网易云 + B站 双音源，并同步听歌。
- 网易云支持扫码登录；也可在个人中心粘贴 Cookie 登录（提交时校验登录态），并支持一键复制 Cookie 迁移到其他设备。房主登录后 VIP 凭证全房间共享
- 网易云歌单 / 每日推荐 / FM，B站音乐分区 / 搜索 / 收藏，各自为独立队列。
- 歌词播放页：频谱可视化、音质角标、翻译 / 罗马音、评论区、弹幕、背景PV视频。
- 顺序播完后自动拉取 B站相关推荐续播。
- 观众可申请切歌 / 调进度 / 添加歌曲，房主开启「自动通过」后全部人都可以控制。

## 视频源

| 来源 | 说明 |
|---|---|
| Bilibili | BV / AV 号、b23.tv 自动解析，支持分 P 视频以及大会员清晰度 |
| MP4 / m3u8 直链 | 直接输入地址播放 |
| WebDAV / FTP / OpenList | 挂载点配置后浏览目录播放；支持多选批量解析入房 |
| Emby / Jellyfin | 服务器媒体库浏览播放 |
| 服务器文件 | root 可浏览服务器磁盘、上传、B站下载（MP4 最高 720P） |

AList 等签名直链过期自动重新解析；挂载直链下发前做校验，源站 TLS 变化自动变更。解析逻辑见[拓展教程 · 视频源与 API 获取逻辑](/advanced/video-pipeline)。

## 字幕

- 原生解析 SRT / ASS / SSA / VTT / SMI / SUB，以 HTML/CSS 直接渲染（不转 WebVTT），保留原始样式信息。
- MKV 内嵌字幕在浏览器端直接提取（稀疏扫描）；PGS 位图字幕（Blu-ray 常用的图形字幕格式）由内置解码器还原成图片渲染。
- 支持自动识别、手动添加外挂字幕文件。

## 弹幕

- Bilibili 官方弹幕、DandanPlay 弹幕匹配、自定义弹幕轨道。
- 支持手动导入本地弹幕文件（B站 XML / B站 JSON / dandanplay JSON）作为一条弹幕轨道。
- 轨道叠加、弹幕翻倍、屏蔽词，屏蔽与删除状态持久化并跨房间同步。

## 实时互动

- 评论面板实时聊天。
- 语音聊天基于 LiveKit（WebRTC 实时通信服务）传输，内嵌于服务端，开箱即用；媒体流走 `3333/udp`，UDP 受限的网络自动回落到 TURN 中继。房管可管理语音成员。链路实现见[拓展教程 · 语音聊天链路](/advanced/voice)。

## 屏幕共享与推流

- WebRTC 屏幕共享（要求 HTTPS），支持共享屏幕或视频画面。
- OBS RTMP 推流（`rtmp://<host>:3334/live`）+ HTTP-FLV 拉流；推流端提供控制栏。

## 主题与外观

- Material You 动态主题：从壁纸提取色彩生成全套色板。
- 自定义主题色 + 颜色强度 + 收藏色板（主题菜单左侧编辑栏）。
- 玻璃拟态（透明度 / 模糊度可调）、自定义背景图（模糊 / 遮罩 / 位移 / 缩放）、精简动画模式。
- 深浅模式跟随系统或手动切换，文字对比度按背景自动适配。

## 移动端

网页版在手机上会自动适配，触屏控件常显、弹窗底部化、滑动条不干扰页面滚动；横屏矮窗口下播放控制收纳到歌手行。

如果希望用独立客户端，手机与平板另有 Android / HarmonyOS 应用，内置 B 站扫码登录与本机播放代理，并接入系统播放控件与后台播放。下载方式、平台差异与手势说明见[手机端 App](/basic/mobile)。
