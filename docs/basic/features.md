# 功能说明

## 一起看房间

- 「开始共享」建房（一起看 / 投屏两种模式）；「加入房间」按房间号、房间列表或分享链接加入。
- 房主控制播放、暂停、跳转、倍速、切换影片，进度实时同步给观众。
- 观众可申请控制（暂停 / 跳转等），房主在播放器左上角收到通知后决定是否通过。
- 房主离线时观众进入自主控制模式；房主主动离开后房间进入宽限期，右上角可一键回到房间；离线超时 10 分钟自动关房。
- 支持房间密码、加入审批、观众权限设置；房主可任命房管（上限 10 名）协助管片、禁言、踢人与语音管理。
- 房间页左下角实时显示上下行流量。

## 一起听音乐

- 网易云 + B站 双音源同步听歌。
- 网易云支持扫码登录，也可在个人中心粘贴 Cookie 登录（提交时校验登录态），并支持一键复制 Cookie 迁移到其他设备；房主登录后 VIP 凭证全房间共享。
- 网易云歌单 / 每日推荐 / FM 与 B站音乐分区 / 搜索 / 收藏各自为独立队列。
- 歌词播放页：频谱可视化、音质角标、翻译 / 罗马音、评论区、弹幕、PV 视频背景。
- 播完后自动拉取 B站相关推荐续播；无推荐时重播。
- 管理端可设置「进入一起听默认页」（网易云 / 哔哩哔哩）。
- 观众可申请切歌 / 调进度 / 添加歌曲，房主开启「自动通过」后直接生效。

## 视频源

| 来源 | 说明 |
|---|---|
| Bilibili | BV / AV 号、b23.tv 短链、番剧 / 影视 ep / ss 链接自动解析；支持分 P 与整季分集（会员集标注）；房主为大会员时全房可看会员画质 |
| MP4 / m3u8 直链 | 直接输入地址播放 |
| WebDAV / FTP / OpenList | 配置挂载点后浏览目录播放，支持多选批量解析入房 |
| Emby / Jellyfin | 浏览服务器媒体库播放 |
| 服务器文件 | root 可浏览服务器磁盘、上传、B站下载（MP4 最高 720P） |

AList 等签名直链过期自动重新解析；挂载直链下发前做校验，源站 TLS 变化自动改写。解析逻辑见[视频源与 API 获取逻辑](/advanced/video-pipeline)。

## 字幕

- 原生解析 SRT / ASS / SSA / VTT / SMI / SUB，以 HTML/CSS 直接渲染（不转 WebVTT），保留原始样式。
- MKV 内嵌字幕浏览器端直接提取；PGS 位图字幕由内置解码器还原成图片渲染。
- 支持自动识别与手动添加外挂字幕。

## 弹幕

- Bilibili 官方弹幕、DandanPlay 弹幕匹配、自定义弹幕轨道。
- 可导入本地弹幕文件（B站 XML / B站 JSON / dandanplay JSON）作为一条独立轨道。
- 轨道叠加、弹幕翻倍、屏蔽词；屏蔽与删除状态持久化并跨房间同步。

## 实时互动

- 评论面板实时聊天，一起听模式在右侧工具坞内嵌评论区。
- 语音基于内嵌的 LiveKit（WebRTC）传输，开箱即用：媒体走 `3333/udp`；UDP 受限时可在管理端切到 TCP（`3337/tcp`）或回落 TURN 中继，语音面板实时显示当前协议。房管可管理语音成员。链路见[语音聊天链路](/advanced/voice)。

## 屏幕共享与推流

- WebRTC 屏幕共享（需 HTTPS），可共享屏幕或视频画面。
- OBS RTMP 推流（`rtmp://<host>:3334/live`）+ HTTP-FLV 拉流，推流端提供控制栏。

## 主题与外观

- Material You 动态主题：从壁纸提取色彩生成全套色板。
- 自定义主题色 + 颜色强度 + 收藏色板（主题菜单左侧编辑栏）。
- 玻璃拟态（透明度 / 模糊度可调）、自定义背景图（模糊 / 遮罩 / 位移 / 缩放）、精简动画模式。
- 深浅模式跟随系统或手动切换，文字对比度按背景自动适配。

## 移动端

网页版在手机上自动适配：触屏控件常显、弹窗底部化、滑动条不干扰页面滚动，横屏矮窗口下播放控制收纳到歌手行。

另有 Android / HarmonyOS 独立客户端，内置 B站扫码登录与本机播放代理，接入系统播放控件与后台播放，详见[手机端 App](/basic/mobile)。
