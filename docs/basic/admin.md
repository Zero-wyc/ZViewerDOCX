# 管理后台与权限

## 角色模型

| 角色 | 权限 |
|---|---|
| `root` | 全部房间控制 / 删除、用户审核、角色管理、系统设置、更新 |
| `admin` | 创建并完全控制自己的房间 |
| `user` | 加入房间、评论弹幕（审核通过的注册用户） |
| `guest` | 同 user（未登录或未审核用户） |

新用户注册后为 `guest` + `pending`，需 root 在管理后台审核通过后升级为 `user`。

## 用户管理

用户列表、审核注册申请、修改角色（仅 admin / user 之间）、删除用户。

## 房间管理

查看活跃房间；强制关闭单个房间（admin / root）、批量删除与清空全部（root）；清理无人房间。

## 系统设置

- 注册方式：直接注册 / 审批注册 / 禁止注册。
- 房间：无人访问自动清理（开关 + 超时小时数）、一起听默认音量、建房权限（仅管理员 / 所有登录用户）、房间权限矩阵（添加影片、移除切换、音乐队列、踢人、禁言五类动作 × 房管 / 管理员 / 普通用户）。
- 语音：自定义 LiveKit 服务器地址（留空按页面域名推导）。
- 房间悬浮入口：是否显示语音聊天按钮（右下角）、是否显示流量统计按钮（左下角）。只影响按钮显隐，不改功能本身。
- 公告：版本更新后是否自动弹出；公告正文取仓库根目录的 `announce.md`。
- 功能开关：Beta 功能（Kazumi、AniSubs 番剧源、B站视频下载），开启后可填规则源与 TVBox 采集源；禁用服务器端 DASH 模式；B站默认解析参数（普通视频 / 番剧影视）。
- 测试开关：允许单用户在多个页面同时登录同一房间（仅供调试，语音成员表会出现重名）。
- 更新：是否接收预发布版本、是否使用镜像更新源、CDN 加速（仅 GitHub 源生效）。

Bilibili 登录凭证按用户绑定（个人资料页），用于大会员清晰度解析，不属于系统设置项。

## 更新

管理后台可检查并应用新版本：默认读 GitCode 镜像上的版本清单（国内直连），关掉镜像开关改走 GitHub Release；也可手动上传压缩包。桌面版由 GUI 自己检查更新，网页端在托管模式下不显示更新入口。机制见[构建与更新](/advanced/build-update)；管理接口清单见 [API 参考](/advanced/api)。
