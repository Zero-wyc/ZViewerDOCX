# 管理后台与权限

## 角色模型

| 角色 | 权限 |
|---|---|
| `root` | 超级管理员：全部房间控制 / 删除、用户审核、角色管理、系统设置、更新 |
| `admin` | 创建并完全控制自己的房间 |
| `user` | 加入房间、评论弹幕（审核通过的注册用户） |
| `guest` | 同 user（未登录或未审核用户自动获得游客身份） |

新用户注册后为 `guest` + `pending` 状态，需 root 在管理后台审核通过后升级为 `user`。

## 用户管理

- 用户列表：查看全部用户与状态。
- 审核注册：通过 `pending` 用户的注册申请。
- 修改角色：root 可将用户升级为 admin 或降级。
- 删除用户。

## 房间管理

- 查看全量活跃房间。
- 强制关闭单个房间（admin / root）、批量删除（root）、清空所有房间（root）。
- 清理无人的房间。

## 系统设置

- 注册方式：直接注册 / 审批注册 / 禁止注册。
- 允许创建房间的用户范围：仅管理员（root / admin）/ 所有登录用户（user / admin / root）。
- 无人访问房间的自动删除开关与超时小时数。
- 是否接收预发布版本更新（main 分支自动构建）。
- 功能开关：启用 Beta 功能（Kazumi / AniSubs 番剧源 / B站视频下载）、禁用服务器端 DASH 模式、CDN 加速。

Bilibili 登录凭证按用户绑定（个人资料页），用于大会员清晰度解析，不属于系统设置项。

## 更新

管理后台可检查并应用新版本（带下载进度），或手动上传压缩包更新。机制见[拓展教程 · 构建与更新](/advanced/build-update)。

管理接口的完整清单见[拓展教程 · API 参考](/advanced/api)。
