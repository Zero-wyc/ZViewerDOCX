# 手机端 App

手机客户端源码在独立仓库 [ZViewerAPP](https://github.com/Zero-wyc/ZViewerAPP)。界面与播放器随安装包分发，应用内填写服务端地址即可连接。

客户端连接的是你自己的 ZViewer 服务端，账号、房间与权限均由服务端决定；媒体来源与可用功能同样取决于服务端与所在平台。

## 支持的平台

| 平台 | 最低版本 |
|---|---|
| Android | 7.0 / API 24 |
| HarmonyOS | 6.1 / API 23 |

两端都只提供 64 位版本。

## 获取安装包

从 [ZViewerAPP Releases](https://github.com/Zero-wyc/ZViewerAPP/releases) 下载；每个版本同时附源码压缩包与 `SHA256SUMS.txt`，可用于校验完整性。

| 平台 | 安装包 |
|---|---|
| Android | `ZViewer-Android-<版本号>-release.apk` |
| HarmonyOS | `ZViewer-HarmonyOS-<版本号>-release.hap` |
| 源码 | `ZViewer-client-<版本号>-source.zip` |

## 连接服务器

1. 启动应用，在连接页填入 ZViewer 服务端地址。
2. 用服务端账号登录；服务端允许游客时也可游客身份进入。
3. 进入房间大厅，选择房间加入。

能否建房取决于服务端设置：限制为仅管理员时，手机端也只能加入他人房间。

## 功能差异

手机端与网页版共用业务代码，房间、片单、弹幕、字幕、音乐与语音行为一致，差异集中在平台能力。

| 能力 | 手机端 | 网页版 |
|---|---|---|
| 同步观影、片单、聊天、弹幕、字幕 | 支持 | 支持 |
| 一起听音乐 | 支持，窄屏重排，平板保留多列 | 支持 |
| 房间语音 | 支持，可申请麦克风、静音、查看成员状态 | 支持 |
| 观看他人屏幕共享 | 支持 | 支持 |
| 发起屏幕共享 | 不支持（无屏幕采集能力） | 支持，需 HTTPS |
| B 站高画质 | 内置扫码登录与本机播放代理 | 需 [ZViewer CLI](/basic/cli) |
| 系统播放控件 | 原生媒体会话，支持通知控制与后台播放 | 由浏览器决定 |
| 屏幕旋转 | 顶栏旋转按钮，全屏时播放器内另有入口 | 由设备与浏览器决定 |

切换标签页、收起面板或更换房间模式都不会结束语音通话。

## 内置 B 站登录与画质

两端均内置 B 站扫码登录与本机播放代理，无需另装 ZViewer CLI。登录后自动选择账号有权限、视频有实际轨道且设备支持的最高普通画质，并排除 HDR 与杜比视界。

最高画质播放失败时有限恢复一次，仍失败则回退 720P，再不行退到更低可用档位。手动选择的画质按影片记住，房主与观众各自在本机生效。

B 站 Cookie 在 Android 上经 Keystore 加密后存入不可备份目录；画质广播不包含本机代理地址与凭据。

## 播放手势

原生播放器在捕获阶段接管视频表面的触屏操作，桌面网页手势不变。

- 单击视频表面只唤出控件，不切换播放状态。
- 一起看：双击画面中间三分之一切换播放 / 暂停。
- 一起看全屏：双击左三分之一后退 15 秒，双击右三分之一前进 15 秒，范围限制在 0 到时长之间。
- 一起听：仅纯净模式的全屏视频启用同一套手势。全屏单击唤出退出按钮，3 秒后自动隐藏，也可用 Esc 或系统返回键退出。

## 后台播放

两端均接入系统媒体会话，锁屏与通知栏显示影片 / 歌曲信息、播放状态与解码后的封面，支持系统播放、暂停、跳转与可用时的切歌。

## 常见问题

**提示无法覆盖安装** — 多为包名或签名与已装版本不一致。先记录服务器地址与个人设置再卸载（会清除本地数据）；调试版与正式版包名不同，可并存。

**画质上不到最高档** — 先确认 B 站账号在该视频能选到该清晰度，再确认设备能解码该编码。HDR 与杜比视界被自动排除属预期行为。

**手机无法发起屏幕共享** — 手机端不提供屏幕采集，只能观看他人共享，需要发起时请用网页版。
