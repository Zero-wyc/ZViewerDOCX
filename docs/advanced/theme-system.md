# 主题系统实现

## Material You 动态主题

种子色经 `@material/material-color-utilities` 生成浅 / 深两套完整 scheme，以 CSS 变量（`--md-sys-color-*`）注入根节点。种子色不变时两套 scheme 在内存中缓存，供文字对比度判定复用。

## 颜色强度

用户选择的种子色与深浅各自的中性基底按 sRGB 线性插值合成**实际种子**：

```
effectiveSeed = color-mix(seed, isDark ? #17161b : #f3f1f7, intensity / 100)
```

- 强度 0-100 滑块实时生效；100 = 纯种子色（默认，与未引入强度前行为一致）。
- 浅 / 深两套 scheme 分别用各自基底合成，保证低强度下派生色仍与背景协调。

## 文字对比度自适应

自定义背景（壁纸 + 遮罩）会改变文字的实际底色，而玻璃面板又叠了一层自己的底色——单一全局判定无法同时满足两类页面。实现为**作用域变量**：

| 变量组 | 判定依据 | 消费方 |
|---|---|---|
| 根节点（无作用域） | scheme 原生值，**永不切换** | 弹窗（portal 到 body）、硬编码色组件 |
| `--lt-raw-*` | 原始背景（底色 → 壁纸 → 遮罩） | 音乐壳、顶栏等文字直坐壁纸的页面 |
| `--lt-glass-*` | 含玻璃层的有效背景 | 播放页、迷你条等主题驱动玻璃面 |

判定规则：对侧 scheme 文字色与当前侧的对比度差 ≥ 1（切换幅度阈值，防临界抖动）才切换。主题驱动面（背板是 surface-container 系）引用 `--lt-glass-*`；文字直坐壁纸的页面根引用 `--lt-raw-*`；其余默认原生。

## 主题编辑栏

主题菜单的一级左栏（打开菜单即展开），Zen 主题编辑器五段式：

1. 模式切换：跟随系统 ✨ / 浅色 ☀ / 深色 🌙（auto 由 `prefers-color-scheme` 监听物化 isDark）。
2. 自定义颜色：取色页（SV 二维区 + 色相条 + Hex 输入）。
3. 颜色强度滑块（0-100）+ 微调按钮。
4. 预设 10 色网格 + 收藏色板。
5. 实时预览（显示强度合成后的实际生效色）。

**收藏色板动作语义**（单向数据流，无隐式副作用）：

- 点圆点 = 应用该颜色（纯切换）。
- 取色页「收藏」= 新增收藏；「更新收藏」= 原位更新被编辑条目（位置不变，仅从收藏色进入取色页时出现）；两按钮在当前色已收藏时禁用并提示原因。
- 🗑 = 仅移出收藏板，不改变正在使用的主题色。

## 玻璃拟态

`--glass-strength`（透明度）/ `--glass-blur`（模糊度）全局变量统一驱动，所有玻璃卡片引用同一组工具类，不各写各的。精简动画模式一键锁定玻璃全不透明、卡片无模糊、背景无模糊，并关闭装饰性动画。

## 入场动画约定

- 入场动画 fill 一律 `backwards`：终帧与自然状态一致。用 `both/forwards` 会永久保持 transform，使元素成为 Backdrop Root，后代玻璃层的 `backdrop-filter` 采样不到外部背景直接失效。
- 弹出面板定位不依赖 transform（keyframes 全程接管 transform 的动画期间偏移会丢失）。
- 滑动条挂 `touch-slider`（`touch-action: none`），防止触屏拖动连带页面滚动。
