# 管理后台

管理后台是 ZViewer 的管理员控制中心，在这里可以管理用户、房间、系统设置和版本更新。

---

## 如何进入管理后台

有两种方式可以进入：

1. **首页按钮**：在首页顶部导航栏或页面中，找到「**权限管理**」按钮，点击即可进入
2. **直接输入地址**：在浏览器地址栏输入 `http://你的服务器地址/admin`（例如 `http://192.168.1.100:3000/admin`）

> 只有 **root** 和 **admin** 角色才能看到和进入管理后台。如果你是普通用户或游客，页面不会显示入口。

## 四个 Tab 概览

进入后台后，你会看到上方有四个选项卡（Tab）：

| Tab | 说明 | 可用角色 |
|---|---|---|
| **用户管理** | 管理用户注册、角色、审核 | 仅 root |
| **房间管理** | 查看和管理所有房间 | root + admin |
| **基础设置** | 修改系统全局设置 | 仅 root |
| **版本更新** | 检查和应用更新 | root + admin |

---

## 用户管理 Tab（仅 root）

### 注册方式设置

1. 在「注册方式」下拉框中，选择你想要的模式：
   - **开放注册**：任何人注册后直接激活
   - **审批注册**：注册后需审核
   - **禁止注册**：关闭注册入口
2. 点击旁边的「**保存**」按钮，设置立即生效

### 用户列表

页面会列出所有已注册的用户，显示以下信息：

- 用户名
- 角色（root / admin / user / guest）
- 状态（active 已激活 / pending 待审核）
- 注册时间

### 审核用户

对于状态为「待审核」的用户，操作栏中会出现「**审核通过**」按钮。点击后该用户升级为正式 user。

### 修改角色

点击用户操作栏中的「**修改角色**」，可以选择将该用户提升为 admin 或降级为 user/guest。

> 注意：不能修改 root 角色的权限，也不能将最后一个 root 降级。

### 删除用户

点击「**删除**」按钮可以移除该用户。此操作不可撤销，请谨慎操作。

## 房间管理 Tab

### 房间列表

这里列出了当前服务器上**所有**的房间，包括其他用户创建的。每条记录显示：

- 房间名称
- 房主（创建者）
- 当前在线人数
- 观看模式

### 视图切换

支持两种查看方式：

- **列表视图**：以表格形式展示，信息更详细
- **卡片视图**：以卡片形式展示，更直观

点击右上角的切换按钮即可切换。

### 批量操作

勾选多个房间左侧的复选框，然后：

- **批量删除**：删除选中的房间
- **删除所有**：清空服务器上所有房间（仅 root）
- **清理无人房间**：自动删除当前没有观众的房间
- **刷新**：重新加载房间列表，获取最新数据

> 删除房间后，房间内的所有观众会被断开连接。

## 基础设置 Tab（仅 root）

### 自动清理

开启后，系统会自动删除长时间无人观看的房间：

- **自动清理开关**：开启/关闭此功能
- **清理时间**：设置房间无人多少小时后自动删除（例如 24 小时）

### 房间创建权限

选择谁可以创建房间：

- **仅管理员**：只有 root 和 admin 可以创建
- **所有用户**：user 也可以创建

### Beta 功能开关

可以开启或关闭以下实验性功能：

- **Kazumi 番剧源**：Kazumi 动漫数据源
- **AniSubs 番剧源**：AniSubs 动漫数据源
- **Bilibili 下载**：B站视频下载功能

开启 Beta 功能可能会影响系统稳定性，请按需使用。

### FFmpeg 引擎（音频转码）

- **允许浏览器端音频转码（ffmpeg.wasm）**：全局许可开关，**默认关闭**。开启后，仅**允许**房主在添加影片时勾选「启用 FFmpeg WASM 引擎」。两者同时开启，播放含浏览器不兼容音轨（DTS / AC3 / EAC3 等）的影片时，才会在浏览器内用 ffmpeg.wasm 实时转码为 AAC（首次加载约 30MB 转码核心）。单独开启本开关不会对任何影片自动转码；关闭则所有影片直推，不兼容音轨可能无声。
- **wasm 引擎下载来源**：ffmpeg.wasm 转码核心的下载来源（作者直链 / 服务器中转 / 自定义链接）。

### Kazumi 规则源配置

如果你使用 Kazumi 数据源，可以在这里配置规则源的 URL。修改后会清空动漫源缓存，重新拉取数据。

## 版本更新 Tab

### 检查更新

点击「**检查更新**」按钮，系统会自动查询 GitHub 上是否有新版本。如果有，会显示新版本的版本号和更新内容。

### 一键更新

点击「**一键更新**」按钮，系统会自动下载最新版本并应用更新。更新过程中服务器会短暂重启，当前正在观看的用户可能会被断开。

### 手动导入更新包

如果服务器无法直接访问 GitHub（例如在内网环境），可以：

1. 在其他电脑上下载更新包（`.zip` 或 `.tar.gz` 格式，不超过 500MB）
2. 在本页面点击「**选择文件**」
3. 选择下载好的更新包
4. 点击「**上传并应用**」

### 接收预发布版本

开启此选项后，检查更新时也会显示预发布版本（Pre-release）。预发布版本包含最新的功能，但可能不够稳定，建议仅在测试环境使用。

## 常见问题

### 看不到管理后台入口

可能的原因：

1. 你当前登录的账号不是 **root** 或 **admin** 角色
2. 你还没有登录，或者登录已过期
3. 页面没有刷新——尝试刷新首页或直接访问 `/admin` 路径

### 按钮是灰色的，点不了

- 某些操作（如审核用户、修改角色）**仅限 root** 使用
- 如果你是 admin，看到灰色按钮是正常的，因为这些功能对你不可用

### 更新失败怎么办

1. 检查服务器是否能够访问 GitHub（能否正常打开 `github.com`）
2. 如果网络受限，使用「手动导入更新包」方式
3. 查看服务器日志，确认是否有更详细的错误信息
4. 如果一键更新反复失败，可以尝试手动下载更新包后上传
