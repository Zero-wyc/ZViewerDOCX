# 视频源 · 新手教程

> 从 B 站追番到自建 NAS，一文掌握 ZViewer 全部视频来源。

---

## 1. 功能概述

ZViewer 支持 **7 种视频来源**，覆盖在线视频平台、直链播放、自建存储和第三方番剧源。在房间的 **「添加影片」** 面板中，你可以根据需求随时切换视频源。

| 来源 | 适用场景 | 是否需要额外配置 |
|------|----------|------------------|
| **Bilibili** | 解析 B 站视频链接 / BV 号，支持大会员清晰度 | 可选（绑定账号获取大会员画质） |
| **MP4 直链** | 直接播放任意可访问的 MP4 视频地址 | 无需 |
| **WebDAV** | 挂载自建 NAS、群晖、NextCloud 等 WebDAV 服务 | 需在个人资料页配置挂载点 |
| **FTP** | 挂载 FTP 文件服务器 | 需在个人资料页配置挂载点 |
| **OpenList** | 挂载 OpenList 目录列表服务 | 需在个人资料页配置挂载点 |
| **番剧源（Beta）** | Kazumi / AniSubs 等第三方番剧数据源 | 需在管理后台开启 |
| **服务器文件** | 浏览服务器本地的视频文件目录 | 仅 `root` 用户可用，需配置根目录 |

> 前三种（Bilibili / MP4 直链 / 挂载）是日常最常用的视频源，建议新手优先掌握。

## 2. Bilibili

Bilibili 是 ZViewer 最常用的视频源。你可以直接粘贴 B 站视频链接或 BV 号，解析后即可播放。

### 2.1 添加 B 站视频

1. 进入房间后，在底部找到 **「添加影片」** 面板。
2. 切换到 **「B站」** Tab。
3. 粘贴 Bilibili 视频链接、**BV 号** 或 **AV 号**，例如：
   - 完整链接：`https://www.bilibili.com/video/BV1GJ411x7o`
   - 仅 BV 号：`BV1GJ411x7o`
   - 仅 AV 号：`av123456`
4. 点击 **「解析」** 按钮，等待解析完成。
5. 解析成功后，视频会自动添加到影片列表中，点击即可播放。

### 2.2 切换清晰度

解析完成后，视频默认使用最高可用清晰度播放。你可以在播放器中点击 **「画质」** 按钮切换清晰度。

> 未登录 B 站账号时，可选的清晰度以 **B 站公开画质** 为准，通常为 1080P 及以下。

### 2.3 绑定 B 站账号（获取大会员清晰度）

如果你拥有 B 站大会员，可以绑定账号以解锁 **1080P 高码率**、**4K** 等大会员专属画质。

ZViewer 提供两种绑定方式：

**方式一：扫码登录**
1. 在 ZViewer 首页，点击右上角 **用户菜单**（显示你的用户名），选择 **「个人资料」**。
2. 在个人资料页，找到 **「Bilibili 绑定」** 区域。
3. 点击 **「绑定 B 站账号」**，页面会显示一个二维码。
4. 打开 B 站手机 App，使用扫一扫功能扫描二维码，确认登录。
5. 绑定成功后，个人资料页会显示你的 B 站用户名和头像。

**方式二：Cookie 登录**
1. 在个人资料页的「Bilibili 绑定」区域，选择 **Cookie 登录**。
2. 粘贴你的 B 站登录 Cookie 字符串。
3. 点击确认，系统验证 Cookie 有效性后完成绑定。

> 绑定后，后续解析的所有 B 站视频都会尝试使用大会员清晰度。如果大会员过期，系统会自动回退到公开画质。

### 2.4 弹幕支持

ZViewer 支持加载 B 站官方弹幕。播放 B 站视频时，点击播放器中的 **「弹幕」** 按钮即可加载和显示弹幕。

## 3. MP4 直链

如果你有一个视频文件的直接 HTTP 链接（以 `.mp4` 结尾或其他可播放格式），可以直接添加到房间播放。

### 添加步骤

1. 在 **「添加影片」** 面板中，切换到 **「直接链接」** Tab。
2. 在输入框中粘贴视频文件的直链 URL，例如：
   - `https://example.com/videos/my-movie.mp4`
   - `https://cdn.example.com/stream/abc123.mp4`
3. 点击 **「添加」** 按钮。
4. 视频会立即添加到影片列表中，点击即可播放。

> 确保链接可公开访问，且服务器未设置防盗链（Referer 限制）。如果遇到播放失败，可以尝试将链接粘贴到浏览器地址栏中测试是否可访问。

### 字幕支持

ZViewer 提供原生字幕系统，**不再转换为 WebVTT**，而是直接解析各字幕格式并用 HTML/CSS 渲染：

- 支持常见字幕格式（SRT、ASS 等），原生解析，样式还原度更高。
- 支持**自动识别**、**自动添加**、**手动添加**三种字幕加载方式。
- 内置 FFmpeg，初步支持 **DTS 音频流**播放（FFmpeg 会在首次使用时自动下载，也支持手动下载安装）。

## 4. WebDAV / FTP / OpenList

这三种视频源需要先在个人资料页配置 **挂载点**，之后在房间内浏览挂载目录选择视频播放。

### 4.1 配置挂载点

1. 点击右上角 **用户菜单** → **「个人资料」**。
2. 在个人资料页，找到 **「挂载点管理」** 区域。
3. 根据你的服务器类型，点击对应的 **「添加」** 按钮（WebDAV / FTP / OpenList）。
4. 在弹出的表单中填写连接信息：

| 字段 | 说明 | 示例 |
|------|------|------|
| **名称** | 给这个挂载点起个名字，方便识别 | `我的 NAS` / `办公室 FTP` |
| **服务器地址** | 服务器 IP 或域名 | `192.168.1.100` 或 `nas.example.com` |
| **端口** | 服务端口号 | WebDAV 默认 `443`（HTTPS）或 `80`（HTTP），FTP 默认 `21` |
| **用户名** | 登录用户名 | `admin` |
| **密码** | 登录密码 | `********` |
| **路径** | 可选，指定起始目录 | `/video`（留空则从根目录开始） |

5. 填写完成后，点击 **「测试连接」** 按钮，确认连接成功。
6. 测试通过后，点击 **「保存」**。

> 如果测试连接失败，请检查服务器地址、端口、用户名和密码是否正确，以及服务器是否允许外部访问。
>
> **OpenList 特别提醒**：请确保你的 OpenList 站点和账户已授予 **离线下载权限**（支持直链播放）和 **WebDAV 权限**，否则无法正常挂载。

### 4.2 在房间内使用挂载点

1. 回到房间，在 **「添加影片」** 面板中，切换到对应的挂载 Tab（**「WebDAV」** / **「FTP」** / **「OpenList」**）。
2. 面板会列出你在个人资料页配置的所有挂载点。
3. 点击一个挂载点，进入目录浏览模式。
4. 浏览文件夹，找到视频文件（支持 `.mp4`、`.mkv`、`.webm` 等格式）。
5. 点击视频文件，即可添加到影片列表并播放。

### 4.3 管理挂载点

在个人资料页的 **「挂载点管理」** 区域，你可以：

- **编辑**：点击挂载点旁的 **「编辑」** 图标，修改连接信息。
- **删除**：点击 **「删除」** 图标移除不再使用的挂载点。
- **测试**：随时点击 **「测试连接」** 检查挂载点是否可用。

## 5. 番剧源（Kazumi / AniSubs，Beta）

番剧源是 ZViewer 的 Beta 功能，支持通过 Kazumi 或 AniSubs 等第三方数据源搜索和播放番剧。

### 5.1 开启番剧源

1. 使用 `root` 账号登录 ZViewer。
2. 进入 **管理后台**（点击右上角用户菜单 → **「管理后台」**）。
3. 在左侧菜单找到 **「基础设置」**。
4. 找到 **「数据源配置」**（`dataSourceConfig`）区域。
5. 开启番剧源开关（Kazumi / AniSubs）。
6. 保存设置。

> 番剧源为 Beta 功能，搜索结果可能不完整，建议搭配 B 站番剧一起使用。

### 5.2 搜索和播放番剧

1. 番剧源开启后，回到房间的 **「添加影片」** 面板。
2. 切换到 **「番剧」** Tab。
3. 在搜索框中输入番剧名称（如 `间谍过家家`、`葬送的芙莉莲`）。
4. 点击 **「搜索」** 按钮。
5. 搜索结果会列出匹配的番剧，点击你想要的番剧。
6. 系统会加载该番剧的剧集列表，选择一集点击播放。

> 首次加载番剧列表可能需要几秒钟，请耐心等待。

## 6. 服务器文件（仅 root）

**服务器文件** 功能允许 `root` 用户直接访问服务器上的本地视频目录，无需额外搭建文件服务。

### 6.1 配置文件根目录

1. 使用 `root` 账号登录。
2. 进入 **管理后台** → **「基础设置」**。
3. 找到 **「服务器文件根目录」** 配置项。
4. 输入服务器上的一个或多个目录路径（逗号分隔），例如：
   - `/mnt/videos`
   - `/data/media`
5. 保存设置。

> 确保 ZViewer 后端进程对这些目录有**读取权限**。目录路径是服务器上的绝对路径，不是浏览器所在机器的路径。

### 6.2 浏览和管理文件

1. 在房间的 **「添加影片」** 面板中，切换到 **「服务器文件」** Tab。
2. 你会看到配置的根目录列表。
3. 点击目录进入浏览模式，可以：
   - **浏览文件夹**：层层进入，找到视频文件。
   - **上传文件**：点击 **「上传」** 按钮，选择本地文件上传到当前目录（支持批量上传，最多 50 个文件）。
   - **新建文件夹**：点击 **「新建文件夹」** 创建子目录。
   - **重命名/删除**：对文件或文件夹执行重命名或删除操作。
4. 点击视频文件，即可添加到影片列表播放。

> 服务器文件的播放通过 ZViewer 后端代理，支持 Range 断点续传，拖动进度条非常流畅。

## 7. ZViewerCLI 本地代理

ZViewerCLI 是一个可选但**强烈推荐**的本地代理客户端，主要解决两个问题：

- **大会员高画质**：通过使用你本地浏览器的 B 站 Cookie 来解析大会员画质地址。
- **CORS 与防盗链**：某些 CDN 会限制跨域请求或校验 Referer，ZViewerCLI 在本地代理转发，自动注入正确的请求头。

### 7.1 安装 ZViewerCLI

1. 打开 [ZViewerCLI Releases 页面](https://github.com/Zero-wyc/ZViewerCLI/releases)。
2. 根据你的操作系统下载对应版本：
   - **Windows**：下载 `zviewer-cli-windows-x64.zip`
   - **Linux**：下载 `zviewer-cli-linux-x64.tar.gz`
3. 解压到任意文件夹。

### 7.2 启动 ZViewerCLI

**Windows**：双击 `zviewer-cli.exe`，或在终端中运行：

```powershell
zviewer-cli.exe
```

**Linux**：

```bash
./zviewer-cli
```

启动后，ZViewerCLI 会自动通过 WebSocket 向 ZViewer 服务器注册。前端**自动检测**到本地代理后，会优先使用本地代理解析视频流。

### 7.3 验证

ZViewerCLI 启动后，在 ZViewer 中播放 B 站视频时，如果看到画质选项中出现了之前不可用的高清晰度（如 **1080P 高码率**、**4K**），说明代理已生效。

> ZViewerCLI 只需要在**观看端**的本地机器上运行，不需要在服务器上安装。如果多人观看，每个人都可以在自己的机器上运行 ZViewerCLI 以获得最佳画质。

## 8. 常见问题

### Q：为什么我添加的 B 站视频解析失败？

A：可能的原因：
- BV 号或链接格式不正确，请检查是否完整复制。
- 该视频为 B 站不可公开访问的视频（如私密投稿）。
- 服务器网络无法访问 B 站 API。
- 如果开启了 ZViewerCLI，请确认 CLI 正在运行。

### Q：MP4 直链添加后无法播放？

A：请检查：
- 链接是否以 `https://` 或 `http://` 开头。
- 链接是否可在浏览器中直接打开。
- 目标服务器是否设置了防盗链（Referer 限制）。
- 视频格式是否为浏览器支持的格式（推荐 `.mp4`）。

### Q：WebDAV / FTP 连接测试失败？

A：常见原因：
- 服务器地址或端口填写错误。
- 用户名或密码不正确。
- 服务器防火墙阻止了外部连接。
- WebDAV 服务器未启用 HTTPS（某些浏览器限制 HTTPS 页面访问 HTTP 资源）。
- 如果是自建 NAS，请检查是否开启了对应服务。

### Q：番剧源搜索不到结果？

A：番剧源为 Beta 功能，可能的原因：
- 管理后台未开启番剧源开关。
- 数据源配置为空或失效。
- 番剧名称不准确，尝试使用日文原名或中文译名。
- 数据源服务器暂时不可用。

### Q：ZViewerCLI 启动后没有效果？

A：请检查：
- ZViewerCLI 是否成功启动（终端是否有报错信息）。
- 是否在**观看端**本地运行（不是在服务器上运行）。
- 防火墙是否阻止了 ZViewerCLI 的网络连接。
- 尝试重启 ZViewerCLI 和刷新 ZViewer 页面。

### Q：如何查看我绑定了哪些视频源？

A：在个人资料页中，你可以看到：
- **Bilibili 绑定状态**：显示已绑定的用户名。
- **挂载点列表**：显示所有已配置的 WebDAV / FTP / OpenList 挂载点。

### Q：服务器文件功能为什么看不到？

A：服务器文件功能仅对 **`root` 角色**可见。如果你使用普通用户账号登录，该 Tab 不会显示。请联系管理员或使用 `root` 账号登录。
