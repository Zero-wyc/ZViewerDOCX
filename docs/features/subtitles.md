# 字幕系统

## 功能概述

字幕让你的观影体验更完整。ZViewer 提供原生字幕系统，**不再转换为 WebVTT**，而是直接解析各字幕格式并用 HTML/CSS 渲染，样式还原度更高。

支持**外挂字幕**与**内封字幕**两大类，并且房主选择的字幕会自动同步给房间内所有观众。

## 支持的字幕格式

| 格式 | 说明 |
|------|------|
| SRT | 最常见的文本字幕 |
| ASS / SSA | 支持定位、颜色、字体等高级样式，渲染时保留 |
| VTT | WebVTT 字幕 |
| SMI | SAMI 字幕 |
| SUB | MicroDVD 字幕 |

## 外挂字幕

外挂字幕是以独立文件形式存在的字幕（如 `movie.srt`、`movie.ass`），有以下几种加载方式。

### 自动识别

播放 WebDAV / FTP / OpenList / 服务器文件源的影片时，ZViewer 会**自动搜索影片同目录下的同名/同前缀字幕文件**并加载，打开字幕设置即可看到。

### 目录浏览

在字幕设置里点 **「浏览目录」**，浏览影片所在目录，选择要加载的字幕文件。

### URL / 文件上传

在字幕设置里直接粘贴字幕文件链接，或上传本地字幕文件。

## 内封字幕

内封字幕（内嵌字幕）是**封装在视频容器里的字幕轨道**。ZViewer 可以识别并提供播放。

> 内封字幕要求**后端能访问视频字节**才能提取。打开「内嵌字幕轨道」按钮即可看到视频内的字幕轨道列表，点击某一条即提取并播放。

各视频源对内封字幕的支持情况：

| 视频源 | 内封字幕可用性 |
|--------|----------------|
| 服务器文件（Server-Files / 上传文件） | ✅ 恒可用（后端本地文件） |
| WebDAV / OpenList | ✅ 仅**服务器中转**模式（直链模式不支持） |
| Emby / Jellyfin | ✅ 直接调用其自带字幕接口，直链 / 中转均可 |
| MP4 直链 / Bilibili | ❌ 不支持 |

### 使用步骤

1. 打开播放器 **设置**，切换到 **字幕** 页。
2. 点击 **「内嵌字幕轨道」**，等待视频内的字幕轨道列出。
3. 在列出的轨道中选择一条，点击即提取并自动开启字幕。

### 内嵌字幕开关

管理员可在 **权限管理 → 基础设置 → FFmpeg 引擎** 下方找到 **「允许内嵌字幕（仅服务器中转）」** 开关，控制整个内嵌字幕功能是否开放。

## 观众同步

房间内**字幕由房主统一控制**。房主加载或切换字幕轨道后，所有观众会自动同步相同配置，无需单独设置。

## 常见问题

### 内封字幕列不出轨道？

确认视频确实包含字幕轨道；对于 WebDAV / OpenList 请确认使用**服务器中转**模式（内网地址会被强制切换为中转）；对于 Emby / Jellyfin 请确认挂载的 API Key 或账号密码可用。

### 样式丢失？

ASS / SSA 内封字幕会保留样式；若源本身是纯文本字幕（如 SRT）则没有样式信息。
