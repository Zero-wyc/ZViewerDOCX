# 主题系统

ZViewer 前端内置 Material You (Monet) 动态主题引擎：

- **从壁纸提取色彩**：基于用户提供的壁纸图片自动生成完整色板。
- **明暗主题切换**：跟随系统或手动切换深色 / 浅色模式。
- **自定义背景**：可设置自定义背景图。
- **玻璃拟态 UI**：毛玻璃效果视觉风格。
- **精简动画模式**：降低动画以提升性能或照顾弱视用户。

## 前端技术栈

主题系统建立在以下前端基础之上：

| 技术 | 用途 |
|---|---|
| React | UI 框架 |
| Vite | 构建工具 |
| Tailwind CSS | 样式方案 |
| Zustand | 状态管理 |

更多前端开发细节见[本地开发](/dev/setup)与[项目结构](/dev/structure)。
