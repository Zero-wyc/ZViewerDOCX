# 房间功能 · 新手教程

> 和好友一起看片、共享屏幕，从这一篇开始。

---

## 1. 功能概述

**房间（Room）** 是 ZViewer 多人互动的核心。你可以创建一个房间，邀请好友加入，一起同步观看视频、共享屏幕画面，或通过语音聊天实时交流。

核心能力：

- **同步观看**：房主播放、暂停、跳转，所有人的画面保持一致。
- **屏幕共享**：分享端实时传输自己的屏幕或应用窗口。
- **观众管理**：房主可以踢人、禁言、审批加入、转交房主。
- **弹幕与评论**：边看边聊，支持 Bilibili 弹幕和画笔批注。
- **断线保护**：房主短暂断线，房间不会立即关闭，观众继续观看。

---

## 2. 房间两种模式对比

| 对比项 | 🎬 一起看（Watch Together） | 🖥️ 屏幕共享（Screen Share） |
|---------|-----------------------------|-------------------------------|
| **做什么** | 所有人同步观看同一个影片链接 | 分享端将自己的屏幕/窗口实时广播 |
| **适合场景** | 一起追剧、看电影 | 演示操作、远程协作、游戏直播 |
| **播放控制** | 房主全权控制，观众可申请控制 | 分享端控制自己的画面 |
| **影片来源** | 粘贴在线视频链接，或从房间列表添加 | 分享端本地屏幕/窗口捕获 |
| **网络要求** | mp4模式承担同步数据流（流量极小），dash模式由服务器中转，服务器带宽要求高 | 较高 |
| **延迟** | 低（同步播放，传输延迟） | 中等（WebRTC 实时传输） |
| **观众数** | 几乎无上限 | 受分享端上行带宽限制 |

> 还有 **OBS 推流模式（`stream-push`）**，适合专业直播场景，详见[屏幕共享与推流](/features/screenshare)。

## 3. 创建房间步骤

创建一个房间只需三步：

1. **打开首页**，点击页面中央的 **「开始共享」** 按钮，或右上角的 **「创建房间」**。
2. **选择模式**：在弹出的窗口中，选择 **「一起看」** 或 **「屏幕共享」**。
3. **自动进入房间**：系统立即创建房间，你自动成为 **房主（Host）**，进入房间界面。

> 💡 **提示**：创建房间不需要注册账号。首次使用时，系统会提示你设置一个**昵称**，方便好友识别。

## 4. 房间界面详解

进入房间后，你会看到四个主要区域：

### 顶部栏

- **房间名称**：显示当前房间的名称，点击可修改。
- **房间号**：一串数字 ID，发送给好友用于加入。
- **在线人数**：显示当前在线观众数。
- **「邀请」按钮**：点击弹出分享方式。
- **「设置」按钮**：齿轮图标，点击打开房间设置面板。
- **「退出房间」按钮**：退出并关闭房间（仅房主可关闭）。

### 播放器区域（一起看模式）

中央主区域是视频播放器，支持：

- **播放/暂停**：点击画面或按空格键。
- **进度条**：拖拽跳转进度。
- **音量控制**：鼠标悬停调节。
- **倍速播放**：支持 0.5× ~ 2× 倍速。
- **全屏**：点击右下角全屏图标。

> 屏幕共享模式下，中央区域显示分享端的实时画面。

### 底部三列卡片

播放器下方有三列卡片，点按展开：

| 卡片 | 内容 |
|------|------|
| **📋 影片列表** | 当前房间已添加的所有影片，可切换、排序、新增 |
| **💬 聊天** | 实时评论——支持文字消息、弹幕模式和画笔批注 |
| **👥 观众列表** | 在线观众，显示昵称和角色（房主/观众） |

### 右侧面板（房间信息）

点击右侧边缘的 **「▶」** 箭头，展开房间信息面板，包含三个 Tab。

## 5. 房间信息面板（三个 Tab）

### 📄 信息 Tab

- **房间号**：复制发送给好友，对方在首页输入即可加入。
- **分享链接**：直接复制链接，发送给好友点击即可加入。
- **房间名称**：房主可修改房间的显示名称。
- **当前模式**：显示「一起看」或「屏幕共享」。

### 🔒 权限 Tab

房主可以设置房间的访问控制：

| 设置项 | 说明 |
|--------|------|
| **房间密码** | 开启后，加入者需输入密码才能进入 |
| **最大人数** | 限制房间最多容纳的观众数（含房主） |
| **加入审批** | 开启后，新观众加入需房主在通知中点击「同意」或「拒绝」 |
| **自动通过** | 开启审批时，白名单或已关注用户自动通过，无需手动确认 |

## 6. 邀请好友的三种方式

### 方式一：房间号

在房间信息面板复制 **房间号**，发送给好友。好友在首页点击 **「加入房间」**，输入房间号即可进入。

### 方式二：分享链接

点击顶部栏的 **「邀请」** 按钮，选择 **「复制链接」**，将链接发送给好友。好友点击链接直接进入房间（如已设置密码，会提示输入）。

### 方式三：房间列表

好友在首页浏览 **「公开房间」** 列表，找到你的房间，点击 **「加入」** 按钮即可。房主可以在权限设置中将房间设为「公开」或「不公开」。

---

## 7. 加入房间的几种情况

根据房主的设置，加入房间有不同的体验：

### ✅ 无密码 + 无需审批

点击链接或输入房间号后，**直接进入房间**，开始同步观看。

### 🔑 有密码

进入房间前弹出 **密码输入框**，输入正确密码后进入。密码由房主在权限 Tab 中设置。

### ⏳ 需审批

房主开启了「加入审批」。你点击加入后，页面会显示 **「等待房主同意」**。房主会收到通知，点击「同意」后你才进入房间。

### 🚫 房间已满

如果房间人数达到「最大人数」上限，你会看到提示 **「房间已满」**，无法加入。

## 8. 房主断线保护机制

ZViewer 有完善的断线保护，避免房主短暂掉线导致房间崩溃：

| 阶段 | 行为 |
|------|------|
| **断线瞬间（0~10 秒）** | 服务器接管播放状态，继续向观众广播当前进度，观众观看**无感知** |
| **断线中（10 秒~10 分钟）** | 观众可自由控制播放（暂停/跳转），房间正常运行 |
| **超时关闭（10 分钟后）** | 房主仍未重连，房间自动关闭，所有观众被移出 |
| **房主重连** | 若在 10 分钟内重新连接，房主自动恢复控制权，播放状态同步回最新位置 |

> 💡 **建议**：如果只是网络波动，无需担心——房间会等你回来。

## 9. 常见问题

### Q：最多可以有多少人一起看？

A：没有硬性上限，但建议根据房主网络带宽和服务器负载控制在 10 人以内以获得最佳体验。

### Q：加入房间需要注册账号吗？

A：不需要。但注册后可以保留头像和昵称设置。

### Q：为什么我看不到影片画面？

A：检查以下几点：
- 影片链接是否有效（是否可公开访问）。
- 是否被浏览器广告拦截插件拦截（尝试关闭插件或使用隐身模式）。
- 是否处于审批等待状态，尚未被房主同意加入。

### Q：屏幕共享模式下，对方能看到我的整个屏幕吗？

A：你可以选择共享**整个屏幕**、**某个应用窗口**或**浏览器标签页**。建议只共享需要的窗口，保护隐私。

### Q：房主退出后房间会怎样？

A：房主退出时会自动关闭房间，所有观众被移出。如果只是断线，有 10 分钟保护期（见第 8 节）。

### Q：如何修改房间密码？

A：房主在右侧面板的 **「权限 Tab」** 中，找到「房间密码」项，点击 **「修改」** 输入新密码即可。

### Q：手机端可以加入房间吗？

A：可以。ZViewer 是 Web 应用，手机浏览器打开链接即可加入，支持基本的播放同步和聊天功能。
