# 屏幕共享与推流

ZViewer 提供两种屏幕共享与推流方式，满足从简单分享到专业直播的不同需求。

| 特性 | WebRTC 屏幕共享（简单） | OBS RTMP 推流（专业） |
|---|---|---|
| 上手难度 | ⭐ 极低，浏览器内一键操作 | ⭐⭐⭐ 需安装 OBS Studio |
| 延迟 | 低（百毫秒级） | 较低（秒级） |
| 画质 | 浏览器编码，基础画质 | OBS 编码，可自定义参数 |
| 音频支持 | 支持（可选） | 支持（OBS 控制） |
| 标注工具 | ✅ 内置画笔、颜色、粗细 | ❌ 需在 OBS 内叠加 |
| 适用场景 | 快速演示、临时会议 | 直播推流、录制、多场景切换 |
| 观众数量 | 适合小规模（P2P/TURN） | 适合大规模（HTTP-FLV 分发） |

---

## WebRTC 屏幕共享（最简单）

无需额外软件，浏览器内即可完成。**要求 HTTPS 访问**（浏览器安全策略限制）。

### 房主操作步骤

#### 1. 创建房间并选择「屏幕共享」模式

1. 点击首页 **「创建房间」** 按钮。
2. 在弹窗中选择 **「屏幕共享」** 模式。
3. 点击 **「确认」** 进入房间。

#### 2. 选择共享屏幕或窗口

1. 进入房间后，点击底部工具栏的 **「共享屏幕」** 按钮。
2. 浏览器弹出系统分享选择框，选择：
   - **整个屏幕** — 分享全部显示器画面。
   - **应用窗口** — 只分享某个程序窗口。
   - **浏览器标签页** — 只分享某个标签页（含音频选项）。
3. 点击 **「分享」** 开始共享。

#### 3. 设置帧率与码率（可选）

点击共享预览旁的 **「画质」** 按钮，可调整：

- **帧率**：默认 15 fps，可选 10 / 15 / 30 fps（还有些bug）
- **码率**：默认 1000 kbps，可拖动或手动输入。

> ⚠️ 帧率和码率越高，画质越好，但网络压力也越大。建议根据上行带宽合理选择（当前帧率选择有些问题，可能被限制在15帧）

#### 4. 共享音频（可选）

在系统分享选择框中，勾选 **「共享音频」**（仅部分浏览器/标签页分享支持）。

#### 5. 暂停与恢复共享

- 点击 **「暂停共享」** 按钮，观众端画面冻结。
- 再次点击 **「恢复共享」** 继续推送。

#### 6. 使用标注工具

分享过程中，可点击 **「画笔」** 按钮打开标注工具栏：

- **画笔开关**：点击激活/关闭画笔。
- **颜色选择**：从预设色板中选取标注颜色。
- **粗细调节**：滑块或按钮调整线条粗细。
- **清空标注**：一键清除所有标注。

> ⚠️ 标注仅叠加在共享画面上，不影响原始内容。

### 观众端操作

- **画中画（PiP）**：点击 **「画中画」** 按钮，将共享画面浮动到窗口一角，方便边看边做其他操作。
- **全屏**：点击 **「全屏」** 按钮放大观看。
- **静音**：点击 **「静音」** 开关控制音频播放。
- **截图**：点击 **「截图」** 按钮保存当前画面（浏览器自动下载）。

> ⚠️ 观众端无需安装任何软件，通过浏览器打开房间链接即可观看。

## OBS RTMP 推流（专业级）

适合需要更高画质、多场景切换、同时推流到多个平台的场景。

### 前置条件

- 安装 [OBS Studio](https://obsproject.com/)（免费开源，支持 Windows / macOS / Linux）。
- 确保 ZViewer 服务端已部署并运行。

### 操作步骤

#### 1. 切换「投屏」模式

1. 房主进入房间后，点击底部工具栏的 **「投屏」** 按钮。
2. 在弹窗中选择 **「OBS 推流」** 子模式。

#### 2. 获取流密钥

1. 点击 **「生成流密钥」** 按钮，系统生成唯一流密钥。
2. 复制显示的流密钥字符串（例如：`zviewer_abc123`）。

#### 3. 下载 OBS 配置文件（推荐，一键导入）

1. 点击 **「下载 OBS 配置」** 按钮，下载 `.json` 配置文件。
2. 打开 OBS Studio。
3. 点击菜单栏 **「场景集合」 → 「导入」**，选择下载的配置文件。
4. 导入完成后，自动切换到此场景集合，推流地址与流密钥已预填。

#### 4. 或手动配置 OBS

如果不想使用配置文件，可手动设置：

| 参数 | 值 |
|---|---|
| 服务器 | `rtmp://服务器IP:3334/live` |
| 流密钥 | 从 ZViewer 房间复制的流密钥 |

1. 打开 OBS Studio → **「设置」 → 「推流」**。
2. **「服务」** 选择 **「自定义…」**。
3. **「服务器」** 填入上述 RTMP 地址。
4. **「流密钥」** 填入复制的流密钥。
5. 点击 **「确定」** 保存。

#### 5. 开始推流

1. 在 OBS 中点击 **「开始推流」** 按钮。
2. 返回 ZViewer 房间，确认状态显示 **「推流中」**。

#### 6. 观众观看

观众无需额外操作，直接通过浏览器观看：

- 观众端自动通过 HTTP-FLV 协议拉流播放。
- 也可直接访问 `http://服务器IP:3335/live/流密钥.flv` 在浏览器或播放器中观看。

> ⚠️ 推流端口：**3334**（RTMP 推流地址）/ **3335**（HTTP-FLV 播放地址）。请确保防火墙已放行这两个端口。

## 生产环境注意事项

### HTTPS 必须

WebRTC 的 `getUserMedia` 接口要求安全上下文，生产环境必须配置 HTTPS。

> ⚠️ 开发环境可使用 `localhost`，但生产环境必须有有效 SSL 证书。

### Nginx 反向代理 HTTP-FLV

HTTP-FLV 端口（3335）**不建议直接暴露**到公网，应通过 Nginx 反向代理 `/live` 路径。

修改 Nginx 配置，将 `http://服务器IP:3335/live/` 代理到同源路径下，同时配置 `VITE_FLV_BASE_URL` 为空字符串以使用同源地址。

### NAT 穿透 — TURN 服务器

严格 NAT 环境下，WebRTC 的 P2P 连接可能失败。需要部署 TURN 服务器（如 [coturn](https://github.com/coturn/coturn)）做中继转发。

### Nginx 配置示例

```nginx
server {
    listen 80;
    server_name your-domain.com;

    # 强制跳转 HTTPS（推荐）
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl;
    server_name your-domain.com;

    ssl_certificate /path/to/cert.pem;
    ssl_certificate_key /path/to/key.pem;

    # 主应用
    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    # HTTP-FLV 流媒体（反向代理 3335 端口）
    location /live/ {
        proxy_pass http://127.0.0.1:3335/live/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

> ⚠️ 将 `your-domain.com` 替换为你的实际域名，并配置有效的 SSL 证书。

## 常见问题

### 观众看不到画面

- **检查 HTTPS**：ZViewer 必须以 HTTPS 访问（WebRTC 强制要求）。
- **检查浏览器权限**：确保浏览器已允许摄像头/屏幕共享权限。
- **查看浏览器控制台**：F12 打开开发者工具，查看是否有报错。
- **NAT 环境**：严格 NAT 下需部署 TURN 服务器，否则 P2P 连接可能失败。

### OBS 推流失败

- **检查服务端状态**：确认 ZViewer 后端及 Node-Media-Server 已启动。
- **检查防火墙**：确保端口 3334（RTMP）未被防火墙拦截。
- **检查流密钥**：确认流密钥与房间内生成的一致，未输入多余空格。
- **查看 OBS 日志**：OBS 菜单 **「帮助」 → 「日志文件」 → 「查看当前日志」**，查找报错信息。
- **服务器地址格式**：确认 RTMP 地址格式为 `rtmp://IP:3334/live`，末尾无斜杠。

### 画面卡顿或延迟高

- **降低帧率/码率**：在共享画质设置中将帧率降至 15 fps，码率降至 500-800 kbps。
- **检查上行带宽**：使用测速工具确认上行带宽 ≥ 1 Mbps。
- **切换网络**：尽量使用有线网络而非 Wi-Fi。
- **关闭其他占用带宽的应用**：如在线视频、大文件下载等。
- **OBS 推流时**：在 OBS 设置中降低输出分辨率（如 720p）或使用硬件编码器。
