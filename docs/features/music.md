# 一起听音乐

## 功能概述

**一起听（Listen Together）** 是 ZViewer 的房间化音乐模块。和好友进入同一个房间，房主控制播放，所有人同步听歌——支持网易云与 B站 双音源、完整的歌词播放页与 CLI 本地高画质代理。

核心能力：

- **双音源**：网易云（歌单 / 每日推荐 / 私人 FM / 搜索）+ B站（音乐分区 / 搜索 / 收藏）。
- **房间同步**：房主切歌、暂停、调节进度，观众实时跟随，内置传输延迟补偿。
- **观众申请控制**：加歌、切歌、暂停、继续、调节进度均可向房主申请，支持一键自动通过。
- **歌词播放页**：复刻 Hydrogen 布局——真实频谱可视化、逐行歌词高亮、翻译 / 罗马音、音质角标、评论区与弹幕。
- **CLI 本地代理**：连接 ZViewerCLI 后可用自己的大会员 Cookie 解析 B站 高画质视频背景。

## 一、双音源支持

| 音源 | 内容 |
|------|------|
| **网易云** | 我的歌单、每日推荐、私人 FM、搜索、我喜欢的音乐、歌曲评论区 |
| **B站** | 音乐分区浏览、搜索、收藏夹、AI 字幕歌词、弹幕、评论区 |

播放列表按音源独立（网易云 / B站 各自维护一个队列），房间内实时同步，两源可自由切换。

### B站 音乐分区

- **自定义栏目**：顶部栏目支持添加与编辑模式，桌面拖拽排序、触屏箭头移动，顺序即时持久化。
- **种类排序**：左栏音乐种类列表同样支持编辑排序，刷新后保持选中种类与顺序。
- **屏蔽词过滤**：按关键词过滤分区内容，取数阶段自动向后跳页补齐，避免过滤后整页为空。

## 二、播放控制与同步

### 房主控制

- 切歌 / 暂停 / 继续 / 进度拖拽 / 播放模式（**按顺序播放** / 单曲循环 / 随机 / 顺序循环）。
- 默认播放模式为**按顺序播放**（不循环，B站推荐续播仅此模式启用）。

### 观众申请控制

| 动作 | 说明 |
|------|------|
| 添加歌曲 | 将歌曲加入房间播放列表 |
| 切换歌曲 | 点播放列表中的歌曲申请播放 |
| 暂停 / 继续 | 同步暂停或继续播放 |
| 调节进度 | 拖动进度条申请跳转 |

- 房主端左上角弹出**审批条**（从上向下滑落动画），点击「通过 / 拒绝」。
- 开启「**自动通过**」后，上述全部动作免审批直接生效。
- 操作成功后，观众端左上角显示「xx 已同步」回执提示。

### 同步机制

- **传输延迟补偿**：观众端按网络延迟对齐播放位置。
- **状态即时同步**：首次进房歌单即时拉取（失败自动退避重试）；断线重连自动重拉房间状态。
- **清空播放列表立即停声**：当前歌曲随队列一起停止，所有成员同步静音——播放始终是房间统一的，不存在本地插播。

## 三、B站推荐续播

顺序播放模式下，播放到队列末尾时点「**下一首**」，自动拉取 3 首 B站 相关推荐加入队列并续播第一条：

- **触发条件**：① 播放模式为「按顺序播放」（顺序循环模式点下一首会回绕队首）；② 当前歌曲是 B站 条目（网易云歌单无此功能）；③ 设置中「B站视频自动连播」已开启。
- 自然播完（不点下一首）不会自动加歌，队列末尾自然停止。
- 设置中可随时关闭自动连播。

## 四、歌词播放页

歌词播放页复刻 Hydrogen Music 布局：

| 区域 | 能力 |
|------|------|
| **左侧播放卡** | 封面四角括号动画、音频真实频谱可视化、音质角标（真实采样率 / 比特率）、UI 透明度调节 |
| **右侧面板** | 逐行歌词高亮、翻译 / 罗马音、网易云与 B站 评论区切换（评论数徽章预加载） |
| **背景层** | 封面模糊度滑块（0–100px）；B站 条目自动解析视频作背景，支持视频背景模糊滑块与切歌封面交叉溶解 |
| **工具栏** | 悬停显隐（触屏常显）；黑白切换、全屏、弹幕开关、播放队列（点击展开 / 再点收回）、设置 |

### UI 透明度（冰霜层方案）

歌词页的「UI 透明度」滑块采用**冰霜层 + UI 图层**分层渲染：底层始终保留完整强度的毛玻璃模糊，上层内容（底色与文字）作为整体淡出——任意透明度下模糊效果都不丢失，模糊与透明度可以同时成立。

### B站弹幕

播放 B站 条目时可开启弹幕：支持层级切换（UI 上方 / 底部）、弹幕设置面板（样式 / 速度 / 屏蔽词 / 轨道设置）、弹幕轨道持久化。

## 五、CLI 本地代理模式

连接 [ZViewerCLI](/cli/) 后，歌词页设置会出现 CLI 面板：

- **高画质视频背景**：使用你本地的大会员 Cookie 解析 B站 视频，大会员专享内容也可播放。
- **分辨率选择**：自动 / 4K / 1080P60 / 1080P+ / 1080P / 720P60 / 720P / 480P / 360P 档位，按 B站 大会员状态过滤——**普通账号最高显示 1080P**，已保存的会员档位会自动回落。
- **进度同步**：背景视频与音频播放进度精确同步，切歌 / 切换分辨率不再卡顿。
- **自动重连**：刷新页面后 CLI 自动重新连接，无需重新开关设置。

## 六、收藏与搜索

- **B站红心收藏**：歌词页与播放条红心一键收藏到指定收藏夹，再次点击取消收藏；收藏状态跨会话回显（通过 B站 官方接口聚合查询，视频在任意收藏夹中即点亮）。
- **收藏夹选择弹窗**：将 B站 视频添加到任意收藏夹。
- **在网易云搜索**：播放 B站 视频时一键提取歌名搜索网易云，支持本地试听、一键收藏到「我喜欢的音乐」（已收藏的歌曲显示红心）。

---

## 七、移动端

- **全面响应式**：播放卡 / 歌词面板自适应布局，工具行竖屏排列，弹窗自动退化为底部 sheet。
- **触屏适配**：无 hover 设备控件常显，滑条拖动不带动页面滚动。
- **语音优化**：手机端语音聊天采用 Opus 40ms 长帧 + 带内 FEC，弱网环境下断音更少、更流畅。

## 常见问题

### Q：推荐续播为什么不触发？

A：需同时满足三个条件：① 播放模式为「按顺序播放」；② 当前歌曲是 B站 条目（网易云歌单无此功能）；③ 设置中「B站视频自动连播」已开启。三个条件缺一不可。

### Q：CLI 分辨率里看不到 4K / 1080P60？

A：分辨率档位按 B站 大会员状态过滤，普通账号最高 1080P。请确认 CLI 使用的是大会员账号的 Cookie；B站 登录状态变化后，重新打开设置面板即可刷新档位。

### Q：观众可以调节播放进度吗？

A：可以。观众拖动进度条会向房主发送申请：房主开启「自动通过」后直接生效；未开启时需在左上角审批条点击「通过」。

### Q：清空播放列表后歌曲还会继续响吗？

A：不会。清空列表时当前歌曲立即停止，所有房间成员同步静音——播放始终是房间统一控制的。

### Q：歌词显示不出来或字幕内容对不上？

A：B站 AI 字幕接口偶发返回错误字幕，ZViewer 已内置多重校验（来源校验 + 时长校验 + 一致性投票），未通过校验时不显示可疑字幕。遇到个别视频字幕缺失属正常现象，可稍后重试。
