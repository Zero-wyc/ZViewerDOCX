# 弹幕系统

## 功能概述

弹幕是飘过视频画面的滚动文字评论，ZViewer 支持多种弹幕来源，让你在看番、看电影时感受到热闹的氛围。

---

## 多轨道弹幕聚合

ZViewer 支持同时加载多个视频源的弹幕并叠加显示。例如 B 站上同一部番剧可能有多个个人上传的版本，每个版本的弹幕是独立的，通过多轨道聚合功能，你可以将多个视频源的弹幕叠加在一起，实现弹幕翻倍的效果，让观影氛围更加热闹。

## 弹幕的三个来源

| 来源 | 说明 |
|------|------|
| Bilibili 官方弹幕 | 从 Bilibili 拉取的原视频弹幕 |
| DandanPlay 弹幕 | 第三方弹幕库，聚合多个来源 |
| 自定义弹幕 | 你和好友在房间内发送的实时弹幕 |

## 加载 Bilibili 弹幕

添加 Bilibili 视频后，弹幕会自动加载，从视频画面右向左飘过。

## 发送自定义弹幕

在右侧面板的 **「实时弹幕」Tab** 中输入文字发送，所有观众都能看到。

## 弹幕轨道管理

在 **「弹幕轨道」Tab** 中可屏蔽关键词、调整弹幕样式（字体/颜色/透明度/速度）、关闭某个弹幕轨道。


## 常见问题

### 弹幕不显示？

确认视频已加载，检查弹幕轨道是否已加载，尝试重新添加视频。
