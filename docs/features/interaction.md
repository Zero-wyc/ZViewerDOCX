# 实时互动

## 评论与批注

- 评论面板：房主与观众可随时发言。
- 批注（AnnotationStroke）：支持画笔数据，房主可在画面上圈画批注，实时同步给所有人。

## 弹幕系统

支持多种弹幕来源：

| 来源 | 说明 |
|---|---|
| **Bilibili 官方弹幕** | 直接拉取 Bilibili 弹幕 |
| **DandanPlay 弹幕** | 聚合第三方弹幕库 |
| **自定义弹幕轨道** | 自建弹幕并同步给观众 |

弹幕数据由后端统一代理获取（`/api/stream/danmaku`），支持弹幕源列表、搜索、集数列表与拉取（XML → 前端格式）。含 B 站 WBI 登录态支持。

## 观众申请控制

观众可申请跳转进度或暂停，房主在播放器左上角查看通知并确认/拒绝。由 `sync-playback` 模块的 `seek-approval` 事件处理。

## 语音聊天

- 房主可配置语音比特率（32 / 96 / 128 / 192 kbps），观众实时收听。
- 基于 WebRTC 实现。

## 播放状态同步

- 房主操作实时同步给所有观众：心跳（`heartbeat`）、轨道同步（`track-sync`）。
- 房主断线时由服务器（播放记忆模块）继续推算并广播播放状态，观众观看不中断。

## 相关 API

弹幕（`/api/stream/danmaku`）：

- `GET /sources`：可用弹幕源列表
- `GET /search`：搜索（含 B站 WBI 登录态支持）
- `GET /episodes`：集数列表
- `POST /fetch`：拉取弹幕（XML → 前端格式）
