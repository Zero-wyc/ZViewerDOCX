# 实时互动

## 功能概述

在 ZViewer 房间里，你和好友不仅可以同步看视频，还能实时互动——发弹幕、聊天、语音、甚至用画笔在画面上圈画。

---

## 一、评论与聊天

评论面板在房间界面的**右侧面板**（CommentPanel），包含三个 Tab。

### 如何发送评论
1. 确保处于 **「评论区」Tab**
2. 在底部的输入框中输入文字
3. 按回车或点击发送按钮
4. 评论会立即显示，房间内所有人都能看到

## 二、弹幕系统

弹幕是飘过视频画面的滚动文字评论。

### 弹幕的三个来源
| 来源 | 说明 |
|------|------|
| Bilibili 官方弹幕 | 从 Bilibili 拉取的原视频弹幕 |
| DandanPlay 弹幕 | 第三方弹幕库，聚合多个来源 |
| 自定义弹幕 | 你和好友在房间内发送的实时弹幕 |

### 加载 Bilibili 弹幕
添加 Bilibili 视频后，弹幕会自动加载，从视频画面右向左飘过。

### 发送自定义弹幕
在右侧面板的 **「实时弹幕」Tab** 中输入文字发送，所有观众都能看到。

### 弹幕轨道管理
在 **「弹幕轨道」Tab** 中可屏蔽关键词、调整弹幕样式（字体/颜色/透明度/速度）、关闭某个弹幕轨道。

## 三、观众申请控制

作为观众，如果你想快进/后退或暂停，可以向房主发送申请。

1. 在播放器上点击暂停/跳转进度
2. 系统提示"已向房主发送申请，请等待确认"
3. 房主的播放器左上角显示通知
4. 房主点击同意或拒绝

如果房主开启了 **「自动通过控制请求」**，申请会自动生效。

## 四、语音聊天

语音面板（VoiceChatPanel）常驻在页面**右下角**。

### 房主开启语音
1. 点击右下角语音面板
2. 开启语音
3. 设置比特率：32 / 96 / 128 / 192 kbps
4. 开启后观众可收听

### 观众收听
语音面板中会显示成员列表，可调节扬声器音量。

## 五、屏幕标注

在屏幕共享模式下，房主可以使用画笔工具在画面上圈画重点，所有观众实时看到。

## 六、播放状态同步

作为观众加入房间后，一切自动同步：
- 房主播放/暂停/跳转/倍速 → 你自动跟随
- 房主断线后服务器接管广播，观看不中断
- 房主离线超 10 分钟房间自动关闭

## 常见问题

### 弹幕不显示？
确认视频已加载，检查弹幕轨道是否已加载，尝试重新添加视频。

### 语音听不到声音？
确认房主已开启语音，检查扬声器，检查麦克风权限，尝试 HTTPS 访问。

### 发送的申请房主没反应？
房主可能不在，稍等片刻。如果开启了自动通过，申请会自动生效。
