# 快速开始

欢迎使用 ZViewer！本教程将带你从零开始，一步步完成下载、启动、登录、创建房间、添加视频并邀请好友一起观影的完整流程。

---

## 浏览器要求

> **强烈推荐使用 Chrome / Edge 等高版本（内核 130+）的 Chromium 内核浏览器**访问 ZViewer。
>
> ⚠️ **不推荐** Safari 和 Firefox 浏览器——由于其对 MSE / MKV / 浏览器端解码与转码等能力的支持差异，可能出现播放卡顿、部分视频无法解码、字幕提取异常等 bug。

---

## 第一步：下载 ZViewer

ZViewer 提供**单文件版**和**源码版**两种运行方式。

### 方式一：单文件版（推荐）

无需安装 Node.js 或 npm，下载后解压即可运行。

1. 打开 [ZViewer Releases 页面](https://github.com/Zero-wyc/ZViewer/releases)
2. 根据你的操作系统下载对应压缩包：
   - **Windows**：下载 `zviewer-windows-x64.zip`
   - **Linux**：下载 `zviewer-linux-x64.tar.gz`
3. 解压到任意文件夹（例如 `D:\ZViewer` 或 `~/ZViewer`）

解压后目录结构如下：

```
zviewer-windows-x64/
├── zviewer-backend.exe     # 后端服务（统一托管前端页面）
├── zviewer-cert.exe        # SSL 证书工具
├── start.bat               # 启动脚本（Windows）
└── start.sh                # 启动脚本（Linux）
```

### 方式二：源码版

适合有 Node.js 开发经验的用户。

```bash
# 克隆项目
git clone https://github.com/Zero-wyc/ZViewer.git
cd ZViewer

# 安装依赖
npm install
```

---

## 第二步：启动服务

### 单文件版启动

**Windows**：双击 `start.bat`，或打开终端运行：

```powershell
# 交互菜单模式
start.bat

# 或直接启动
start.bat start
```

**Linux**：

```bash
./start.sh start
```

启动后终端会显示交互菜单：

```
========================================
  ZViewer 服务管理
========================================
  1) 启动服务 (HTTP)
  2) 仅启动后端（可选 HTTP / HTTPS）
  3) 停止服务
  4) 重启服务
  5) 查看状态
  6) 查看日志
  7) 一键签发 SSL 证书
  8) HTTPS 启动（自动签发证书）
  9) 构建前后端（源码版）
  0) 退出
```

初次使用选择 **1) 启动服务 (HTTP)** 即可。

### 源码版启动

```bash
.\start-prod.bat start      # Windows
./start-prod.sh start       # Linux / macOS
```

### 启动后访问

服务启动后，打开浏览器访问：

- **HTTP 模式**：`http://localhost:3333`
- **HTTPS 模式**：`https://localhost:3333`

---

## 第三步：登录系统

首次启动时系统会自动创建超级管理员账号：

| 用户名 | 密码 |
|--------|------|
| `root` | `root` |

1. 打开浏览器访问 `http://localhost:3333`
2. 你会看到首页，底部显示 🟢 **已连接** 表示服务运行正常
3. 点击页面右上角的用户头像框，进行登录
4. 输入用户名 `root`、密码 `root`，点击「登录」

> 系统会自动为未登录用户分配**游客（guest）身份**，游客可以加入房间观看，但不能创建房间。

---

## 第四步：修改默认密码（重要！）

生产环境部署后**必须立即修改默认密码**，否则他人可登录你的管理后台。

1. 登录后，点击右上角用户菜单（显示你的用户名），选择「个人资料」
2. 在个人资料页点击「编辑信息」按钮
3. 在弹出的编辑窗口中，**右侧列**找到「修改密码」
4. 输入原密码 `root`、新密码（至少 4 位）、确认新密码
5. 点击「确认修改」

> 同时建议修改 JWT 密钥（`JWT_ACCESS_SECRET` 和 `JWT_REFRESH_SECRET`），详见[环境变量](/dev/env)。

---

## 第五步：创建房间

1. 修改完密码后，回到首页（点击左上角 ZViewer 图标或导航栏）
2. 点击 **「开始共享」** 按钮
3. 你会进入房间页面，此时因为还没有 roomId，会显示**创建房间面板**
4. 选择房间模式：
   - **一起看（watch-together）**：所有人同步观看同一部影片
   - **屏幕共享（screen-share）**：分享端共享屏幕画面
5. 创建成功后，页面自动进入房间

> 如果「开始共享」按钮被禁用，说明管理员设置了"仅管理员可创建房间"，请联系管理员或使用 `root` 账号登录。

---

## 第六步：认识房间界面

进入房间后，你会看到以下界面布局：

### 顶部区域
- **返回按钮**：退出房间
- **房间名称**：显示当前房间名，房主可点击编辑
- **模式切换**：`一起看` / `投屏` 切换（房主可用）

### 中间区域
- **播放器**：视频播放区域，占大部分空间

### 底部控制卡片（三列网格）
- **房间信息**（左侧）：显示房间号、分享链接、观众列表、权限设置
- **影片列表**（中间）：当前房间已添加的影片
- **添加影片**（右侧）：从各种视频源添加影片

### 右侧面板
- **评论/弹幕/聊天**：与观众实时互动

---

## 第七步：邀请好友加入

你的房间创建后，需要告诉好友房间号：

1. 在房间中，找到底部左侧的**房间信息面板**
2. 切换到「信息」Tab
3. 你会看到：
   - **房间号**：一串数字 ID（例如 `123456`）
   - **分享链接**：可直接复制给好友的完整链接
4. 点击房间号或链接旁的复制按钮，发送给好友

好友可以通过以下方式加入：

**方式一：通过房间号**
1. 在首页点击「加入房间」按钮
2. 输入房间号，点击「加入」

**方式二：通过房间列表**
1. 在首页点击「房间列表」按钮
2. 从列表中找到你的房间，点击「加入房间」

**方式三：通过分享链接**
1. 直接打开你分享的链接

> 如果房间设置了密码，好友加入时需要输入密码。如果开启了"需要审批"，房主会收到加入请求通知，需点击同意。

---

## 第八步：添加视频

房间创建后，需要添加视频才能开始观看。

1. 在房间界面，找到底部右侧的**「添加影片」面板**
2. 选择你想要的视频来源：

### 使用 Bilibili 视频（最常用）

1. 在「添加影片」面板中选择 **B站** Tab
2. 粘贴 Bilibili 视频链接、BV 号或 AV 号
   - 例如：`https://www.bilibili.com/video/BV1GJ411x7o` 或 `BV1GJ411x7o`
3. 点击解析按钮，等待解析完成
4. 解析成功后，视频会自动添加到影片列表中

### 使用直链（支持mp4，m3u8等）

1. 选择 **直接链接** Tab
2. 输入视频文件的直链 URL（如 `https://example.com/video.mp4`）
3. 点击添加

### 使用 WebDAV / FTP 挂载

1. 先在个人资料页或管理后台配置好挂载点
2. 在「添加影片」面板中选择对应的挂载 Tab
3. 浏览目录，找到视频文件，点击播放

---

## 第九步：开始观影

添加视频后，一切就绪！

- **房主**：点击影片列表中的视频，即可开始播放。播放控制（播放、暂停、跳转、倍速）会实时同步给所有观众。
- **观众**：加入房间后，播放器会自动同步房主的播放进度，无需任何操作。
- **弹幕**：可以在右侧面板发送弹幕，或加载 Bilibili 官方弹幕。
- **评论**：在评论区发言，与好友实时交流。
- **字幕**：视频支持原生字幕渲染，可自动识别、自动添加或手动加载字幕文件（支持 SRT、ASS 等格式）。

## 端口说明

| 服务 | 端口 | 说明 |
|---|---|---|
| 后端服务（统一入口） | 3333 | HTTP / HTTPS API、WebSocket、前端静态文件、SPA 回退 |
| RTMP 推流 | 3334 | OBS 推流端口（独立端口，RTMP 为 TCP 二进制协议，无法与 HTTP 复用） |
| HTTP-FLV 拉流 | 3335 | 直播流播放（Node Media Server，通过后端 `/live` 代理转发） |

HTTP 模式下，用户通过 `http://localhost:3333` 访问所有功能。
