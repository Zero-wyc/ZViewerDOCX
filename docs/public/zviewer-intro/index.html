What is ZViewer

它不是又一个播放器。
它是你和朋友的线上放映厅 + 听歌房——
开一间房、丢一个链接，同帧看片，同步听歌。

房

一间房，一个节奏

房主点播放，画面同步播放、歌曲一句不差地同步走。暂停、拖进度、换内容，全房同步。

链

一个链接

不用提前下载、不用传文件。B 站链接、网盘目录、媒体库，输进来就能一起看。

屏

什么设备都能进

浏览器打开即用，手机竖屏横屏都适配。不用装任何插件，也不用对方是技术党。

01 · 同步观看

片源随便挂，进度永远同步

B 站追番、网盘剧集、自己的媒体库——不管影片从哪来，进了房间就是同一个影片。房主短暂掉线？服务器继续播放，大家接着看。

B

哔哩哔哩

输入 BV 号就能播，分 P、清晰度随便切，弹幕一并到位。

O

OpenList / 网盘

挂上网盘目录，剧集列表直接在房间里翻，点哪集看哪集。

E

Emby / Jellyfin

媒体库整库接入，存储库选片，家里 NAS 变成共同片库。

W

WebDAV / FTP

各类存储服务通通支持，签名直链过期也自动重新解析。

M

MP4 直链

任何能访问的视频地址，直接输进房间开播。

服

服务器文件挂载

直接挂载部署服务器上的影片目录，本地硬盘里的收藏秒变全房间共享片库，不依赖任何外部网盘。

权

想自己动手？

观众可以申请控制权，房主同意后可进行暂停、跳转等播放操作——换片等大权仍留在房主手里，且随时可以收回。

03 · 字幕

字幕格式通吃，主流格式均支持

项目中的字幕均经过统一转换处理后再渲染超多格式兼容与全程稳定，背后是前端稀疏探测字幕引擎。

统一转换渲染 · Unified Rendering"我陪你走到最后，能不能不要回头。"
SRTASSSSAVTTSMISUBMKV 内嵌字幕
换

统一转换，坦诚相告

所有字幕先统一转换再渲染：ASS 花字、卡拉OK 特效等虽无法原样显示，但文字内容与时间轴精准无偏差，任何片源不翻车。

容

超多格式兼容

SRT / ASS / SSA / VTT / SMI / SUB 一网打尽，MKV 内嵌字幕还能直接从容器里提取，冷门老片也有字幕可用。

擎

稀疏探测字幕引擎

前端稀疏探测字幕引擎：按需探测、只处理当前需要的字幕段，长片、多字幕轨也轻快不卡顿。

04 · 高画质

大会员画质，全房间一起享受

只有你有 B 站大会员？没关系，整个房间都能跟着看高画质——走 CLI 模式几乎不费服务器流量，三种模式按需选择。

推荐

CLI 本地代理模式

在你自己的电脑上跑一个小程序，用你的大会员账号在本地解析高画质片源，视频流直接送到每个人屏幕上。服务器只负责"喊话"，一点带宽都不吃，高码率大片随便放。

1080P 高码率4K 超清高码率大片零服务器流量
备用

服务器转发模式

没跑 CLI 也不慌：服务器帮你把高画质视频流中转给全房间，画质照样拉满，只是更吃服务器带宽。多种模式随时切换，怎么方便怎么来。

开箱即用无需安装全员高画质
兜底

MP4 直链转发模式

B 站返回的 MP4 直链地址经后端代理转发后直接播放，不依赖 DASH 解析——兼容性最好，即点即看，最高画质 720P，作为前两种模式的稳妥兜底。

直链播放兼容性最佳最高 720P即点即看

CLI 与服务器转发基于 B 站 DASH 高画质片源，MP4 直链转发提供最佳兼容性兜底，三种模式按需切换。

05 · 播放能力

能直连的直连，该转码的转码

ZViewer 按格式智能选择播放引擎：浏览器支持的原样直播，部分不支持的交给 playersvideo 在浏览器端转码——服务器不装任何工具。

直

原生直连 · video.js

浏览器原生支持的格式——MP4、WebM 等——直接交给 video.js 播放：零转码、零等待，即点即看，稳稳当当。

转

转码播放 · playersvideo

遇到浏览器部分不支持的 MKV / AVI / TS / WMV，自动切到 playersvideo 引擎：解析容器、重封装后继续播，DTS / AC3 / EAC3 音轨实时转 AAC——全程在浏览器完成。

直连MP4 / WebM 等支持的格式→video.js 直接播放→即点即看 ✓
转码MKV / AVI / TS / WMV→playersvideo 解析容器→音轨实时转 AAC→重封装流畅播放 ✓
