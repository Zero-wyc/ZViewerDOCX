## 新增「手机端 App」页面

- 需求：「请你在项目文档里添加关于 zviewer 手机端的信息」，来源项目 `F:/Code/ZViewer/ZViewerAPP`。
- 调研依据：`ZViewerAPP/README.md`、`package.json`、`capacitor.config.ts`、`PORTING.md`、`docs/mobile-release-maintenance.md`、`docs/releases/client-1.5.0.md`、`CHANGELOG.md`、`ZV-HarmonyOS/README.md`。
- 关键事实（写进文档前逐条核对过）：
  - 手机端是独立仓库 `Zero-wyc/ZViewerAPP`，不是加载远程网页的地址壳；界面与播放器随安装包分发。
  - Android 与 HarmonyOS 均为正式版 1.5.0 / versionCode 150，目标服务端 v4.2.1；iOS 是独立的 Expo / React Native 工程，开发中，未覆盖 B站代理、语音与完整媒体能力。
  - 安装包命名：`ZViewer-Android-<版本号>-release.apk`、`ZViewer-HarmonyOS-<版本号>-release.hap`、`ZViewer-client-<版本号>-source.zip`，附 `SHA256SUMS.txt`。标签 `client-v1.5.0`。
  - 正式包名 `com.zviewer.mobile`，调试包 `com.zviewer.mobile.debug`（可并存）。Android 最低 API 24，HarmonyOS 最低 6.1 / API 23。
  - 与网页版的差异：手机端不发起屏幕共享；内置 B站扫码登录与本机 Go 播放代理，无需 CLI。
  - 手势：一起看视频表面单击只唤控件，中间三分之一双击播放/暂停；全屏左右三分之一双击 ±15 秒。一起听仅在纯净模式全屏启用相同手势。双击判定要求同区域、相邻点、间隔 ≤320ms。
  - 弹幕手机端默认「随屏幕缩放」，字幕默认 12px（平板 15px）。
- 产出：新建 `docs/basic/mobile.md`（142 行，MDN 风格）。
- 接线：`.vitepress/config.mts` 的 `/basic/` 侧边栏插入「手机端 App」；`docs/basic/index.md` 本分区目录加一行；`docs/basic/features.md` 的「移动端」一节改为指向新页；根 `README.md` 的「最新功能变更」表加一行、基础教程列表加一项。
